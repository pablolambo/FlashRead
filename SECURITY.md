# Security policy

## Supported versions

FlashRead has not had a release yet. Security fixes are made on the `master` branch.

## Reporting a vulnerability

Please **do not** report security vulnerabilities in public issues, discussions or pull requests.

Report them privately with GitHub's
[private vulnerability reporting](https://github.com/pablolambo/FlashRead/security/advisories/new).
Include a description of the problem, steps to reproduce it and, if possible, the affected file or commit.

You can expect a first reply within 7 days. Once the issue is confirmed and fixed,
it will be disclosed in a GitHub security advisory, crediting you unless you prefer otherwise.
